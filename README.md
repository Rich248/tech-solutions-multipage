# Tech Solutions — current yellow-accent version

This is the current six-page static website version. It uses the blue editorial technology palette with the yellow `#f5c542` accent, responsive navigation, delayed mobile sidebar motion, the full-color header logo, and the transparent white footer logo.

Deploy this directory from the repository root on the `plain-static` branch. The six entry pages are `index.html`, `about.html`, `services.html`, `work.html`, `why-us.html`, and `contact.html`. All current images are stored under `assets/` and the `assets/html-source/` subfolder.

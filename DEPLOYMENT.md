# Current Deployment Version

This repository contains the current yellow-accent Tech Solutions static website.

The deployable root includes six HTML pages, the shared `site.js` and `styles.css` files, and the `assets/` directory required by the pages. For Vercel, use the repository root with no build command and deploy from the `main` or `plain-static` branch.

This marker is included in the fresh deployment commit so the current version can be identified clearly in GitHub.
